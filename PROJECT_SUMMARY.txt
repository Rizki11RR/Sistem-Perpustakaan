==========================================
DATABASE SCHEMA
==========================================

Tables:
- buku              (13 columns, UUID primary key)
- kategori          (3 columns)
- anggota           (11 columns, UUID primary key)
- petugas           (8 columns, UUID primary key)
- peminjaman        (13 columns, UUID primary key)
- sync_log          (6 columns, auto increment)

Indexes:
- kode_buku, kategori, nomor_anggota
- status, deleted, synced
- Foreign keys dengan CASCADE

Default Data:
- 10 kategori buku
- 1 admin user (admin/admin123)

KEAMANAN & BEST PRACTICES
==========================================

✅ Prepared Statements (PDO)
✅ Password hashing (SHA-256)
✅ Token authentication (Bearer)
✅ Input validation & sanitization
✅ XSS prevention (escapeHtml)

✅ Error logging (not display)
✅ Config file excluded from Git
✅ Soft delete (sync-friendly)

⚠️ BEFORE PRODUCTION:
1. Ganti password admin default
2. Generate strong API token (32+ chars)
3. chmod 600 api/config.php
4. Aktifkan HTTPS/SSL
5. Set proper CORS origin
6. Disable display_errors
7. Setup database backup cron

==========================================
CARA PENGGUNAAN
==========================================

MODE 1: OFFLINE-ONLY (No Server)
1. Buka index.html di browser
2. Login: admin / admin123
3. Ganti password
4. Mulai input data
5. Backup manual dengan Ekspor JSON

MODE 2: ONLINE (With Server)
1. Import schema.sql ke MySQL
2. Upload files ke hosting
3. Copy config.sample.php → config.php
4. Edit DB credentials & API token
5. Aktifkan HTTPS (wajib untuk PWA)
6. Set API URL & Token di app
7. Klik Sinkronkan
8. Data tersimpan ke server
